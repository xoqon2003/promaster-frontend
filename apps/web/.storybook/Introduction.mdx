## Maqsad

UstaTop.uz'ning barcha sahifalarida **izchil visual til** va **accessible** komponentlarni ta'minlash.

---

## Token ishlatish

### Rang (Color)
```css
/* Brand */
bg-brand-500     /* Asosiy ko'k */
text-brand-700   /* To'q ko'k */

/* Trust tiers — HECH QACHON hardcoded rang yozmang */
text-trust-verified   /* Yashil */
text-trust-pro        /* Oltin */
text-trust-premium    /* Binafsha */

/* Semantic */
text-success   text-warning   text-danger   text-info
bg-success-bg  bg-warning-bg  bg-danger-bg  bg-info-bg
```

### Tipografiya (Typography)
```tsx
<h1 className="font-display text-4xl font-bold">  {/* Manrope */}
<p className="font-sans text-base">               {/* Inter */}
<code className="font-mono text-sm">             {/* Monospace */}
```

### Motion
```css
transition-all duration-[var(--motion-fast)]     /* 150ms */
transition-all duration-[var(--motion-normal)]   /* 300ms */
```
